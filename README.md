# Страница газификации — вентшахты.рф

Вёрстка страницы «Вентиляция для газового котла» по макету из Claude Design.

Чтобы посмотреть локально — открыть `index.html` в браузере, сборка не нужна.

## Что где лежит

| Файл | Назначение |
| --- | --- |
| `index.html` | Разметка всех шести секций |
| `assets/styles.css` | Стили: токены дизайн-системы вентшахты.рф + классы вместо инлайнов прототипа |
| `assets/main.js` | Табы объектов в галерее и модалка видео |
| `assets/img/` | Оптимизированные фото (`srcset` 640/960/1080–1440, progressive JPEG) |

Стек — обычные HTML/CSS/JS без сборки: страницу можно открыть файлом или положить на тот же
хостинг, где стоит текущий сайт. Внешних зависимостей нет, кроме Google Fonts
(Golos Text + Caveat) — как и в макете.

## Секции

1. **Галерея «обычно / наша работа»** — табы объектов, две карточки сравнения, плашка с CTA.
2. **«Газификацию можно сдать — или сделать один раз на 20 лет»** — текстовый блок.
3. **«Чем мы отличаемся от частного мастера с Авито»** — 4 нумерованные карточки + основатель.
4. **«Почему у нас заказывают, зная, что дороже»** — список выгод + мозаика из трёх фото.
5. **Видео** — тёмная секция, три карточки.
6. **Частые вопросы** — семь раскрывающихся ответов на нативном `<details>`.

## Что перенесено из прототипа один в один

Цвета, размеры, отступы, радиусы, тени, тексты и переносы строк соответствуют макету.
Инлайновые стили прототипа разобраны в классы, значения не менялись.

## Отличия от прототипа (сознательные)

- `<image-slot>` из дизайн-инструмента заменены на пунктирные заглушки с тем же текстом
  подсказки — их видно и на странице, и в разметке (рядом стоят комментарии `TODO`).
- Фото пережаты в progressive JPEG и отдаются через `srcset` (исходный PNG весил 1,06 МБ,
  стало 147 КБ) — для страницы под платный трафик это заметно на LCP.
- Табы получили роли `tablist / tab / tabpanel` и переключение стрелками; FAQ работает
  без JS. Без JS страница читается целиком, показан первый объект.
- Добавлены `:focus-visible` и `prefers-reduced-motion` из базовых правил дизайн-системы.

## Мобильная версия

Макет был нарисован под 1280 px, поэтому под телефон добавлены три брейкпоинта: 900 px
(планшет), 640 px (телефон) и 380 px (узкие экраны вроде iPhone SE). Что поменялось:

- Табы объектов вместо трёх строк подряд стали горизонтальной лентой со свайпом
  (подписи вроде «Каркасный дом, Сергиев Посад» на 360 px в строку не помещаются).
- Мозаика фото в блоке «Почему у нас заказывают» на телефоне перестроена из мелких плиток
  в кадры по ширине экрана — 16:10 сверху и два 4:3 под ним.
- Кнопка «Получите проект вентиляции» — на всю ширину.
- Тач-цели доведены до 44 px: табы и номер телефона (был 24 px — по такому пальцем
  не попасть, а это главное действие на мобильном).
- Поджаты внутренние отступы карточек и секций, межстрочные в заголовках отпущены
  с 1.08 до 1.15 — на 26 px плотный интерлиньяж макета читается хуже.
- Размеры текста не уменьшались: заголовки 26 px, подзаголовки 18 px, основной текст
  и ответы FAQ 17 px.

Проверено в headless Chromium на 320 / 360 / 390 / 414 / 768 px: горизонтального
переполнения нет ни на одной ширине, за экран ничего не выходит.

## Что нужно от клиента, чтобы страницу можно было публиковать

1. **Фото основателя** — вертикальный кадр, примерно 840 × 1120. Положить в
   `assets/img/founder.jpg` и заменить заглушку в секции 3.
2. **Три фото для мозаики** в секции 4: котельная (котёл и вытяжка), шахта с дымником на
   фасаде, воздуховоды в котельной.
3. **Фото второго и третьего объекта** для галереи «до/после» — по паре на объект. Пути
   прописываются в массиве `OBJECTS` в `assets/main.js`, разметка подставится сама.
4. **Ссылки на три ролика** — вписать в `VIDEO_URLS` в `assets/main.js` (embed-адрес
   YouTube / VK / Rutube). Пока ссылок нет, карточки статичные и не кликаются; как только
   адрес появится, карточка начинает открывать плеер в модальном окне. Нужны ещё превью-кадры
   (`assets/img/video-1..3.jpg`) и реальный хронометраж вместо `1:02 / 0:58 / 1:04` из макета.
5. **Ответ на вопрос «Куда вы выезжаете?»** — в макете остался `[ЗАГЛУШКА]`:
   выезжаете ли за пределы Московской области и на каких условиях.
