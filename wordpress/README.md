# Лендинги на WordPress — плагин «Вентшахты: лендинги»

Плагин переносит обе страницы — «Ремонт вентиляции» (`remont.html`) и
«Вентиляция для газового котла» (`index.html`) — на WordPress как **шаблоны
страниц**. Вёрстка та же, что на GitHub Pages, пиксель в пиксель.

Готовый архив: **[`dist/ventshaty-landings.zip`](dist/ventshaty-landings.zip)**.

## Что делает плагин

- Добавляет два шаблона в блок «Шаблон» редактора страницы.
- На этих страницах снимает стили темы и глобальные стили `theme.json`,
  чтобы тема не ломала вёрстку. Шапку и подвал темы тоже не выводит —
  у лендинга свои.
- **Отправляет заявки с формы на почту** через `wp_mail`. После отправки
  человек уходит на страницу «Спасибо». Если письмо не ушло, человек видит
  «Не получилось отправить заявку. Позвоните…», его не уводит на фальшивое
  «Спасибо», и кнопку можно нажать снова.
- Защита от спама: скрытое поле-ловушка для ботов и не больше 5 заявок в час
  с одного IP.
- Настройки: **Настройки → Вентшахты** — почта для заявок, страница
  «Спасибо», адрес для кнопки «Монтаж шахты под ключ».

## Установка — 5 минут

1. **Плагины → Добавить новый → Загрузить плагин** → выбрать
   `ventshaty-landings.zip` → «Установить» → «Активировать».
2. **Страницы → Добавить новую.** Заголовок, например «Ремонт вентиляции»;
   ярлык в URL — например `remont-ventilyacii`.
3. Справа в панели **«Страница» → «Шаблон»** выбрать
   «Вентшахты: ремонт вентиляции». Текст в редакторе можно не писать —
   на странице с этим шаблоном он не выводится. Опубликовать.
4. То же для газификации, если нужна на WordPress: шаблон
   «Вентшахты: вентиляция для газового котла».
5. **Настройки → Вентшахты:** проверить почту для заявок (по умолчанию
   `info@krovmast.ru`), страницу «Спасибо» (по умолчанию
   `вентшахты.рф/thankyou_page.php`) и вписать в «Ссылка „Монтаж под ключ“»
   адрес страницы газификации из пункта 4.
6. Открыть страницу, отправить тестовую заявку со своим номером и
   убедиться, что письмо пришло.

## Важно: письма и спам

`wp_mail` на многих хостингах отправляет письма через PHP `mail()`, и они
падают в спам или не доходят. Перед запуском рекламы поставьте плагин
**WP Mail SMTP** и отправляйте через почтовый ящик домена. Проверьте на
тестовой заявке, что письмо пришло во «Входящие».

## Кэширующие плагины

Форма работает с закэшированной страницей: одноразовые токены (nonce),
которые протухают в кэше, в ней специально не используются. Отдельно
настраивать кэш не нужно.

## Заявки в Битрикс24 (по желанию)

Плагин вызывает хук `vsh_lead_received` после каждой заявки. Чтобы заявка
заодно падала лидом в Битрикс24, создайте в Битрикс24 входящий вебхук
с правом CRM и добавьте в `functions.php` дочерней темы или в плагин
Code Snippets:

```php
add_action( 'vsh_lead_received', function ( $lead, $sent ) {
	// Адрес вебхука: Битрикс24 → Разработчикам → Входящий вебхук
	$webhook = 'https://ВАШ-ПОРТАЛ.bitrix24.ru/rest/1/КЛЮЧ/crm.lead.add.json';
	wp_remote_post( $webhook, array(
		'timeout' => 5,
		'body'    => array( 'fields' => array(
			'TITLE'    => 'Сайт: ' . $lead['title'],
			'NAME'     => $lead['name'],
			'PHONE'    => array( array( 'VALUE' => $lead['phone'], 'VALUE_TYPE' => 'WORK' ) ),
			'COMMENTS' => 'Ситуация: ' . $lead['stage'] . "\nСтраница: " . $lead['page'],
			'SOURCE_ID'=> 'WEB',
		) ),
	) );
}, 10, 2 );
```

Ключ вебхука — секрет: не публикуйте его в репозитории.

## Как обновлять

Источник правды — HTML в корне репозитория (`remont.html`, `index.html`,
`assets/`). Шаблоны в `ventshaty-landings/templates/` генерируются, руками
их не правим.

1. Поменять HTML/CSS/JS в корне, проверить на GitHub Pages.
2. Пересобрать плагин: `python3 wordpress/build.py`. Скрипт скопирует
   `assets/`, соберёт шаблоны и `dist/ventshaty-landings.zip`.
3. На сайте: **Плагины → Добавить новый → Загрузить плагин** → тот же zip →
   «Заменить текущую версию». Кэш браузера сбросится сам: версия файлов
   берётся из времени их изменения.

## Если что-то не так

- **Страница выглядит «как тема», а не как лендинг** — не выбран шаблон
  в пункте 3, или тема не поддерживает выбор шаблонов у страниц (редко).
- **Съехали отступы или шрифты** — какой-то плагин подключает свои стили
  на всех страницах. Стили темы плагин снимает сам; стили других плагинов
  нужно отключить на этой странице в их настройках.
- **Нужно оставить стили темы** — добавить
  `add_filter( 'vsh_dequeue_theme_styles', '__return_false' );`.
- **Заявки не приходят** — см. «Письма и спам» выше.

## Что проверено

Плагин прогнан на PHP 8.4 с имитацией окружения WordPress — упрощёнными
заглушками его функций:
- шаблоны открываются, стили темы сняты, наши стили и скрипт подключены,
  битых ссылок на файлы нет;
- в браузере (Chromium) форма на обеих страницах доходит до обработчика,
  письмо уходит на `info@krovmast.ru`, человек попадает на «Спасибо»,
  горизонтальной прокрутки нет;
- бот с заполненной ловушкой получает «успех», но письмо не отправляется;
  короткий телефон отклоняется; HTML в полях вырезается; шестая заявка
  за час с одного IP блокируется; при сбое почты человек видит телефон
  для звонка.

На живом WordPress плагин не запускался — проверьте тестовой заявкой
(пункт 6 установки).
